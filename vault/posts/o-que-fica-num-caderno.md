Quando uma ideia funciona, é fácil esquecer o que fez dela uma boa escolha. Volto às notas para encontrar as alternativas que descartei, as perguntas que anotei e as condições que mudaram no meio do caminho.

## O contexto também é uma descoberta

Uma anotação ganha valor quando registra o que eu sabia na hora de decidir. Se escrevo só “mudei o menu”, daqui a um mês vou ter que refazer a investigação. Se anoto que o índice estava escondido para quem chegava pelo celular, consigo testar outra solução sem repetir o começo.

O que vale guardar não é toda a conversa: é o detalhe que faz a decisão voltar a fazer sentido.

## Três linhas já bastam

### Modelo de entrada

Uma entrada não precisa virar ensaio. Às vezes, três linhas dão contexto suficiente para retomar uma decisão na semana seguinte:

#### Exemplo em código

```python
pergunta = "O que ainda não entendi?"
decisao = "O que escolhi hoje?"
proximo = "O que vale testar?"
```

O caderno fica útil quando consigo reabrir uma ideia sem precisar começar do zero. Para isso, a última linha importa tanto quanto a primeira: deixa uma porta aberta sem me obrigar a atravessá-la agora.
